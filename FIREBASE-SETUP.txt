SETUP FIREBASE MAXIEL (WAJIB SEKALI)

Fitur akun dan chat komunitas memakai Firebase Authentication, Cloud Firestore, dan Firebase Storage.

1. Buka Firebase Console: https://console.firebase.google.com/
2. Pilih project coffee-spark-ai-barista-ed3e0.
3. Authentication > Sign-in method > aktifkan Email/Password.
4. Firestore Database > Rules: salin isi firestore.rules dari ZIP ini, lalu klik Publish.
5. Storage > Rules: salin isi storage.rules dari ZIP ini, lalu klik Publish.
6. Pastikan Cloud Firestore Database dan Storage sudah dibuat pada project yang sama.
7. Upload isi ZIP ke repository GitHub Pages. File rules perlu dipublikasikan melalui Firebase Console atau Firebase CLI; mengunggah file rules ke GitHub saja tidak mengubah aturan Firebase.

Cara kerja:
- Pengunjung perlu masuk atau membuat akun dengan email/password.
- Saat masuk, profil disimpan pada koleksi userProfiles dengan UID akun Firebase.
- Dashboard menampilkan jumlah dokumen profil yang sudah terdaftar dan daftar pengguna terlihat di halaman Chat Komunitas.
- Pesan teks, foto, video, dan audio dikirim ke ruang komunitas yang sama.
- Lampiran dibatasi maksimal 20 MB.

Penting:
- Firebase Auth tidak mengizinkan situs publik mengambil daftar seluruh akun Auth secara langsung. Daftar dashboard berisi akun yang sudah pernah masuk dan tersimpan di userProfiles. Untuk mengimpor akun Auth lama yang belum pernah masuk, diperlukan proses Admin SDK tepercaya di server/Cloud Functions.
- Jangan pernah menaruh service account private key di GitHub Pages.
- Uji dengan dua akun berbeda. Aturan Firestore/Storage harus dipublikasikan agar fitur bisa dipakai.
- Pemutar musik asli dalam app.js dipertahankan; bagian musik tidak diganti oleh fitur chat.


LOGIN GOOGLE
Untuk tombol GANTI AKUN GOOGLE, buka Firebase Console > Authentication > Sign-in method, aktifkan provider Google, lalu simpan. Tambahkan domain GitHub Pages ke Authentication > Settings > Authorized domains.
Chat komunitas hanya mengirim teks; foto, video, lampiran, dan voice note tidak didukung dalam chat.
